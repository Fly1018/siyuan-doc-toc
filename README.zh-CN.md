# 文档目录生成器（siyuan-doc-toc）

[English](./README.md)

在当前文档开头生成或刷新一个可点击跳转的目录，使用原生标题块引用，不依赖第三方库。

插件基于 [plugin-sample-vite-svelte](https://github.com/siyuan-note/plugin-sample-vite-svelte) 构建：Vite 8 + TypeScript + Svelte 5。

## 功能

- **一键生成**：点击顶栏列表图标，在文档开头插入目录。
- **原地刷新**：再次点击就地更新，目录块 ID 保持不变，不会打断已有引用。
- **点击跳转**：目录项是原生块引用，点击即可跳到对应标题。
- **自动更新**：停止输入后按设定延迟刷新已存在的目录。
- **层级控制**：可只收录 h1–h3 等指定层级，忽略更深的标题。
- **自定义标题**：目录首行文字可修改，留空则使用当前语言默认值。
- **面板预览**：通过命令「打开目录面板」查看当前文档的标题结构和一键生成按钮。
- **多语言**：中文 / English 界面与默认目录标题。

## 使用

1. 打开任意包含标题的文档。
2. 点击顶部工具栏右侧的目录按钮（图标为列表）。
3. 首次点击会在文档开头插入一个列表块，首行为「📑 目录」，其下按标题层级生成块引用。
4. 再次点击会就地更新已有目录。

也可以在命令面板中搜索「打开目录面板」，查看标题数量、层级和名称预览。

## 设置

打开「设置 → 插件 → 文档目录生成器」：

| 设置 | 说明 |
| --- | --- |
| 自动更新目录 | 默认关闭。开启后停止输入约 2 秒自动刷新已有目录，不会自动创建目录。 |
| 自动更新延迟 | 1~10 秒，仅在自动更新启用时生效。 |
| 目录标题 | 目录首行文字；留空使用默认标题（中文为「📑 目录」，英文为「📑 Contents」）。 |
| 收录标题层级 | H1–H6 可选，默认全部收录。选择 H1–H3 时忽略 h4–h6。 |

设置保存在插件私有目录 `data/storage/petal/siyuan-doc-toc/settings.json`，不写入笔记。

## 行为说明

- 目录块带有自定义属性 `custom-toc-generator="true"`、`custom-toc-source="<文档ID>"`，并记录内容签名 `custom-toc-signature`。
- 内容签名让自动更新在重启、切换文档后仍能判断目录是否过期，避免无意义的重复写入。
- 更新时优先原地替换目录块内容，块 ID 不变；只有旧目录块缺失或已被改成其他类型时才会删除并新建。
- 新建后只标记「第一个子块且为列表、且内容包含目录标题」的块；验证失败会报错而不会误标记其他块。
- 目录只收录标题（h1–h6），最多缩进 5 级。
- 文档没有标题时只提示，不写入任何内容。
- 自动更新会跳过：光标位于目录块内、窗口未获得焦点、文档中没有目录、标题结构未变化。
- 目录是普通列表块，可手动编辑或删除；删除后再次点击按钮即可重新生成。

## 数据影响

- 只读取当前文档的 ID、标题大纲、文档标题与文档变更通知（仅在自动更新开启时）。
- 只写入当前文档：更新既有目录块（必要时清理重复旧块），或在文档开头新建目录块。
- 不新建文档，不修改其他文档，不修改工作空间配置。
- 无网络请求，无第三方运行时依赖。

## 兼容性

- 前端：`desktop`、`desktop-window`、`browser-desktop`。
- 最低思源版本：3.7.0。

## 开发

```bash
pnpm install
pnpm dev      # 监听构建到 dist/
pnpm check    # TypeScript + Svelte 检查
pnpm build    # 生产构建到 dist/
```

发布新版本时同步修改 `package.json` 与 `plugin.json` 的 `version`，然后推送 `v<version>` 标签；GitHub Actions 会自动构建并上传包含 `package.zip` 的 Release。

## 已知限制

- 多窗口/分屏时以最近获得焦点的编辑器为准。
- 生成过程中若文档被外部修改，重试即可恢复。
- 自动更新会进入撤销历史，连续撤销时可能先撤销目录更新。
- 若手动清除了目录块上的自定义属性，插件会把它视为普通列表并重新生成目录；旧列表不会被自动接管。
